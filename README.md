请你自行判断你的症状，并查找与之对应的解法。

我写的玩意，都是拿来用的，放心大胆一点，大不了就是预设错了重新来过嘛。
我写这些都是为了让每个症状都能与解法匹配。哲学篇是静态的“全能医疗箱”，给姑娘们的话是具体的、动态的“手术流程录像”，请各取所需。
如果还有困惑请详细描述你的痛和你的症状，我会很乐意用与你的交流作为素材扩充那份影像资料库。当然，前提是你愿意公开你的痛苦。

如果你没觉得痛，不认为自己有病，那也没关系，此处随时接受您未来有可能的折返。只是我这位作者，保不定会什么时候变成无法互动的状态。
这只是一份保险，不是什么负担。只是一条可以选择的路，一个能走的方向，从来不算唯一的方向。
